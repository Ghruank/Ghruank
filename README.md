## Ghruank Kothare

### Quantitative Finance

- **[Option Selling Strategy Optimiser](https://github.com/Ghruank/option-selling-strike-optimiser)**: Selects put-writing and covered-call strikes by comparing market-implied and real-world exercise probabilities (GARCH, filtered historical simulation) on 2.7M NSE option prices. Backtested over 2020–2025 across US, EU, UK and Indian indices.
- **[Exotic Option Pricing Model](https://github.com/Ghruank/exotic-option-pricing-model)**: Prices barrier, Asian, digital, lookback and chooser options using Monte Carlo, Heston, Black-Scholes and binomial models.
- **[trading-bench](https://github.com/Ghruank/trading-bench)**: A distributed platform that benchmarks matching engines under adversarial load, with sandboxed execution and fill validation against a reference engine.
